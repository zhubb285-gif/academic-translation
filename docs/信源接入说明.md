# 信源清单与检索能力

既有 TransFlow-J 的 `data/sources/sources.json` 注明源自《信源问题.docx》。本次迁移取得的是该配置，未取得原始 Word 文件，因此不能声称已重新逐条核对原文。

迁移保留一级 9 类、二级 20 类、三级 11 类；删除与旧项目有关的次数统计，另列 9 类学科补充来源。分级遵循这份项目清单，不能把它解读为通用的网站权威性排名。尤其不能把“三级弱源”和先前程序中“三级专业期刊”混用。

## 使用

在项目「术语查证」中点击某个术语的「信源与证据」，选择级别并筛选来源。中文站使用中文术语；英文站优先使用输入框中的英文候选译法，修改后点击「更新检索词」。

- 「站内检索」：可生成带词的站内检索网址。旧项目中政府网、教育部、术语在线和中科院的规则已迁移；中科院保留双重编码要求。
- Springer、ERIC、新华丝路的结果页于 2026-10-19 实际打开核对；新华丝路的路径参数使用 URL 编码后再做 Base64 的形式。Baker Hughes 的 GET 搜索参数来自其官网表单。原有 Nature、ISO、IEEE、ACM、MeSH 规则保留。
- 新华网中文搜索路由通过官网提交确认，英文路由来自英文官网 `home.js`；两者均实际打开带词结果页。中国日报的 `query` 参数来自官网表单并核对结果页。国家标准全文公开系统的 `p.p2` 参数来自官方 `searchS` 函数及结果页。
- OSTI 官网提交后实际使用 `/search/semantic:{q}`；`/search?search=...` 会忽略词语，不能作为可用带词链接。
- 每条卡片和人工证据只显示一个带词站内检索入口。取消 Google `site:` 替代搜索和重复的官网／原始来源按钮；未接通的网站显示「暂未接通带词站内检索」。没有可识别域名的“未识别短链”不能生成可靠链接。
- 三级来源保留清单用于识别，不显示搜索入口，不能添加或标记为有效译法证据。历史记录保留，但按当前清单重新标级和提示。

目前 49 类目录中有 16 类提供站内带词检索规则（其中部分学术站可能要求安全验证或登录），22 类尚未接通，11 类三级弱源禁用。目录之外的历史新华网卡片也使用官方站内规则。接入状态与网站是否收录某个词是两回事，结果页可能没有匹配记录。

OnePetro 和 ScienceDirect 本次访问遇到网站安全验证，未绕过验证，未将它们标记为已验证的站内检索。其他链接规则也不代表保证网站始终可访问。

本次纠正两处旧清单信息：`imsilkroad.com` 官网标明为新华社主办的“新华丝路”，原清单“国新办丝路网”名称不准确，现保留原名称作为历史匹配别名；“国家标准全文公开系统”的官网入口改为实际返回“国家标准全文公开”的 `openstd.samr.gov.cn/bzgk/gb/`，避免将标准目录查询页面当作全文系统。

## 自动化边界

当前自动读取并保存原文的接口是术语在线。其余网站提供人工查证入口，不能宣称系统已经自动遍历所有一级来源或已取得两份独立二级证据。新清单不会自动覆写用户已确认的译法。

配置文件：`backend/app/data/sources.json`、`backend/app/data/source_search_templates.json`。`source_catalog.py` 负责分类与目录，`source_links.py` 负责检索链接；人工证据 API 和旧卡片共用这些规则。
